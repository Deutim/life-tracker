# Life Tracker

Aplicação pessoal para acompanhar hábitos, tarefas e evolução ao longo do tempo.

O projeto também faz parte do meu processo de aprendizado em desenvolvimento de software, aplicando na prática conceitos de programação, Git e GitHub.

## Objetivo

Criar uma aplicação simples que permita registrar e acompanhar hábitos do dia a dia, evoluindo gradualmente conforme meus conhecimentos em programação avançam.
